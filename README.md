# Kamera V60

Aplikasi web kamera untuk **vivo V60 5G**, dibuka lewat Chrome di HP.

**Buka aplikasi:** https://tjktskamuda.github.io/kamera-v60/

## Fitur

- Tiga mode: **Foto**, **Video**, dan **Sinematik** (video portrait dengan latar blur dan pindah fokus seperti iPhone)
- Video 4K 30 fps, 1080p 30/60 fps, dan 720p 30 fps, disimpan sebagai MP4 (H.264) bila didukung Chrome
- Tombol lensa 0,6× / 1× / 3× untuk ultra-wide, utama, dan telefoto, plus kamera depan
- Stabilisasi EIS berbasis giroskop (dihitung aplikasi); OIS hardware aktif otomatis di lensa utama dan telefoto
- Ketuk untuk fokus dan eksposur, cubit untuk zoom, timer foto, grid 3×3, galeri sesi dengan Simpan dan Bagikan

## Cara pakai

1. Buka alamat di atas dengan Chrome di vivo V60.
2. Ketuk **Mulai kamera**, lalu izinkan kamera dan mikrofon.
3. Agar terasa seperti aplikasi: menu ⋮ Chrome → **Tambahkan ke layar utama**.

## Catatan

- Kamera hanya bisa dipakai lewat alamat `https://` seperti GitHub Pages.
- Lensa yang tidak dibuka vivo untuk browser diganti zoom dari lensa utama. Jika urutan lensa tertukar, perbaiki di ⚙ Pengaturan → Pemetaan lensa.
- Mode Sinematik memakai model AI MediaPipe, dimuat dari internet saat pertama dibuka, dan direkam 1080p 30 fps.
- Foto dan video diproses di HP; tidak ada yang dikirim ke server.
